# Plan next — powered by Grok Build

Each platform has its own desk. Click **Plan next game** (Facebook) or **Plan next app/game** (Android).

**No API key.** Click **Plan next** → the studio copies a full prompt (catalog included) → paste it into Grok Build with this `Facebook-Games` folder open → Grok researches and writes the pack.

A copy of the prompt is also saved at `data/research-inbox/prompt.md`.

## What a run does

1. Inventory packs, library, and workspaces on **both** platforms.
2. Live market research for that platform.
3. 3-stage filter + red team (may drop).
4. Write one info pack + `MARKET-RESEARCH.md`.

Keep Grok Build pointed at `Facebook-Games` while you click the button if you want *this* chat to do the work.
