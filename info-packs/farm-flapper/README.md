# Farm Flapper

One-time import from the existing `flappy-duck` project (player title **Farm Flapper**). Future titles should use **Plan next** + **Copy build prompt**, not a folder drop.

## Elevator pitch

One-thumb farm arcade: flap, shoot eggs at pests, ride mounts, land eggs in the farmer’s basket, multiply the score, share.

## Core loop (5-second test)

1. Tap flap.  
2. Shoot a pest or grab a coin.  
3. Clear a gap.  
4. Die → tally → challenge a friend.
