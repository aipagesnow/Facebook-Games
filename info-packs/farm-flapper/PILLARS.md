# Pillars

- **Core loop** — Flap, shoot, survive, tally.  
- **Social** — `shareAsync` challenge; optional Instant Games leaderboard.  
- **Retention** — Best score, named board, mounts/clovers/lives.  
- **Monetization** — None at import. If ads later: only after a scored run.  
- **Discovery** — Duck + egg icon; farm dusk cover.  
- **Live-ops** — Seasonal skins, weekend multipliers.
