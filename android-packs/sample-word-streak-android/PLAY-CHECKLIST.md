# Play Console — upload checklist

## Create app

- [ ] Create app as **Game** (not App) — cannot change later
- [ ] Default language `en-US`
- [ ] Free
- [ ] Package name reserved: `com.apexarcade.wordstreakduels`

## Store listing

- [ ] App name
- [ ] Short description ≤ 80
- [ ] Full description
- [ ] High-res icon 512×512
- [ ] Feature graphic 1024×500
- [ ] At least two phone screenshots
- [ ] Category + tags

## App content

- [ ] Privacy policy HTTPS URL
- [ ] Data safety form
- [ ] Ads declaration
- [ ] IARC content rating
- [ ] Target audience (not children)

## Release

- [ ] Upload keystore backed up offline
- [ ] Play App Signing accepted
- [ ] Signed `app-release.aab` on Internal testing
- [ ] Tester install from opt-in link
- [ ] Promote to Production when dashboard items are green
- [ ] Package name saved in Games Studio Library
