# Pillars — Android

- **Core loop** — Seed → type last-letter chain → score → share. Same as Instant Game.
- **Social** — Android share sheet with seed + score. Play Games services are optional later, not v1.
- **Retention** — Daily seed, streak, optional rewarded freeze.
- **Monetization** — AdMob rewarded only after a scored round. Never mid-input. Play Billing later for cosmetics if needed.
- **Discovery** — 512 gold-tile icon; feature graphic sells “60-second daily ladder”.
- **Live-ops** — Theme weeks and limited dictionaries. No live multiplayer required.
