# Focus Pulse (Android app)

Utility **app** (not a game). One tap starts a 60-second focus pulse. Local streak only.

Create this on Play as an **App** (Productivity / Tools) — never as a Game.

## Build guidance

Bare HTML/JS + Capacitor. No ads in v1. Output: `android-apps/focus-pulse/`.

## Docs

See `PLAY-CHECKLIST.md` for Play Console steps. This pack exists so the studio can track **apps** beside **games**.
